# HSG Agentic AI Executive Course — Website

Next.js static-export site for the University of St. Gallen's Agentic AI executive course, deployed via Vercel.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Produces a static export in `out/` (see `next.config.ts`: `output: "export"`).
